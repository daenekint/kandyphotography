# K&Y Photography — GitHub website

Dit is een statische website voor GitHub Pages.

## Installeren
1. Upload de volledige inhoud van deze map naar je GitHub repository.
2. Ga naar **Settings → Pages**.
3. Kies **Deploy from a branch** en selecteer de branch waarin `index.html` staat.
4. Voeg jullie eigen foto's toe in `assets/images/` met de bestandsnamen die al in de HTML staan.
5. Vervang de `#` links voor Instagram/Facebook door de echte profielen.
6. Stel in Google Search Console `https://kandy-photography.com/sitemap.xml` in als sitemap.

## Belangrijk
Het contactformulier gebruikt voorlopig `mailto:`. Voor een betrouwbaar formulier zonder lokaal e-mailprogramma moet je een formulierdienst of backend koppelen.
